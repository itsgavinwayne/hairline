做一方印稿时用的印面示意：白文、朱文、四字印各一张，标了尺寸和字区。它是给做印的人看的图，不是放进界面的组件。

- 画布 48×48，印面占中间 40×40，四角是系统里印章的那四个不等的小角。
- 虚线框是「字区」：字要落在里面。白文的字区大（34×34），字撑满；朱文的字区小一圈（30×29.5），字不贴边栏。
- 朱文的底边比另外三边重，所以字区的下沿也跟着抬高了半个单位。
- 这套系统**不提供篆字**。印面里放什么字、字怎么写，由做印的人准备，规矩见手册的「印稿规范」一节。
- 空白印面的文件在资源的 Seals 组里，可以直接在上面排字。

**无障碍**

- 每张示意图照预览在 `<svg class="hao-sealguide">` 上写 `role="img"` 和 `aria-label`，读屏把它当一张有名字的图。
- `role="img"` 会把图里的字区和尺寸文字收进这张图，不逐个念；尺寸的说明照预览写在图旁边的段落里。

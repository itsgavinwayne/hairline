一方朱砂印，是使用这套系统的人或产品自己的署名，按篆刻的规矩做成白文和朱文两种。

用 `<span class="hao-seal">字</span>`，印文由你提供：姓氏、名字或产品名里的字。预览里的「印」「使用者印」「札记」都只是占位。

**两种刻法**

- 白文（默认）：朱底留白字。笔画粗，字撑满印面，四周只留一线红边。用在品牌露出处：启动页、关于页、导航栏。
- 朱文（`hao-seal--outline`）：细边栏加细笔画，底边比另外三边略重，印才坐得稳。用在落款处：卡片右上角、文章末尾。

**三种印面**

| 类名 | 印面 | 印文 |
| --- | --- | --- |
| （默认） | 正方 | 一个字 |
| `hao-seal--four` | 正方 | 四个字，自右上起竖读，写成「某某之印」这样的格式 |
| `hao-seal--tall` | 长方 | 两个字竖排，作闲章或引首章，放在一段文字的开头 |

**四个尺寸**：`hao-seal--sm` 24px、默认 40px、`hao-seal--lg` 64px、`hao-seal--xl` 96px。四字印不小于 64px，长方印不小于 40px；24px 只用单字。

- 印面四角是略不相等的小角，像手工切出来的石章，不是应用图标那种大圆角。不要改成 `radius-sm` 或正圆。
- 印文用最重的宋体（白文）或中等字重的宋体（朱文）。字在印面里靠竖排对齐，天然居中；不要自己加内边距或行高去调。
- 默认的宋体字只是占位。想要一方真正的印，照手册的「印稿规范」做一份篆字印稿，用 `<span class="hao-seal hao-seal--art"><img src="…" alt=""></span>` 换掉文字，尺寸类照用。这套系统不提供篆字，印面的尺寸和字区见 `SealGuide`。
- 一屏一方。同屏如果已有删除按钮或报错，就不再放印。一个产品只用一个印文，定了就不换。
- 不旋转，不做旧，不加纹理，不加阴影。
- 作为标志时加 `role="img"` 和 `aria-label`（写产品名，如「某某 印」）；纯装饰时加 `aria-hidden="true"`。
- 英文界面里也用汉字印，不换成字母；加 `lang="zh"` 和英文的 `aria-label`。
- 落印的动效用 `hao-seal--stamp`，只在完成时刻播一次，用法见 `Stamp`。平时的印是静止的。

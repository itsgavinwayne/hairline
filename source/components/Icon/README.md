这套系统自己的图标：39 个，线性，单色。

在界面里用 `<i class="hao-icon hao-icon--名字" aria-hidden="true"></i>`，颜色跟随所在文字；`hao-icon--sm` 是 20px。同样的图形也作为 SVG 文件放在资源的 Icons 组里，给设计稿和文档用。

**画法**

- 24px 网格，图形占中间 18 到 20px，四周留白。
- 线宽 1.5px，线头和转角都是圆的。不填色，只有个别小圆点是实心的。
- **留气口。** 封闭的轮廓都留一个小缺口，不画死：圆环在右上断开，方框在左下断开。像毛笔收笔时提起来的那一下，也让图标在小尺寸下更透气。这是这套图标和别家线性图标最不一样的地方。
- 只画必要的笔画。能用三笔说清的不用五笔。

**取自器物的几个**

- 有七个图标不用通行的画法，改取文房和器物的形：编辑是一支笔（`edit`），文件夹是函套（`folder`），图片是一幅画轴（`image`），札记是一册线装书（`notes`），书签是一盏灯（`bookmark`），署名是一方印（`seal`），首页是月洞门（`gate`）。
- 其余的保持通行的画法。搜索、关闭、箭头、四个状态这类，人一眼要认出来，不为了有特色去改。
- 新画这一类时照「图形与素材」里的表去找：先想清要表达什么，再找一样本来就有这个意思的东西；缩到 24px 认不出来的不用。

**用法**

- 尺寸只用 24px 和 20px。更大的地方用小品或标志，不放大图标。
- 图标不单独承担含义：旁边有文字，或者按钮上有 `aria-label`。图标本身一律 `aria-hidden="true"`。
- 颜色跟随文字，不单独给图标上色。状态图标的颜色由所在的提示条决定。
- 四个状态各有固定的图标：`info`、`success`、`warning`、`error`。不要互换，也不要用别的图标表示状态。
- 勾选框、筛选标签、轻提示里的勾是另一个笔形（提勾），是那些控件自己的一部分，不在这套图标里。

**加新图标**

先看这 39 个里有没有意思相近的。真的没有，照上面的画法画：同样的网格、线宽、圆头，并留一个气口，再加进这张表。不要混用别家的图标。

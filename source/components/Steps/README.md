分几步完成一件事时，告诉人一共几步、现在在第几步。序号用汉字数字。

`<ol class="hao-steps">`，每个 `<li>` 里是一个 `.hao-steps__n`（一、二、三）和这一步的名字。做完的加 `hao-steps__item--done`，当前的加 `aria-current="step"`。

- 二到五步。超过五步，拆成几件事。
- 序号只用在真的有先后顺序的地方；并列的几项不要编号。
- 序号是宋体汉字，圆里一个字。英文界面改用阿拉伯数字。
- 做完的是 `tint` 实心，当前的是 `tint` 圆环，没到的是灰环；连线随之变色。状态同时靠实心、空心和文字粗细区分。
- 窄屏放不下时只显示「第二步，共三步」和当前步的名字。
- 根元素是 `lang="en"` 时，序号的字体自动换成 Newsreader，内容写阿拉伯数字。
- 窗口窄于 600px 时，只有当前一步显示文字，其余各步只剩数字，读屏仍然能读到每一步的名字。
- 步骤之间的连线：走过的是实线，没走到的是针脚（虚线），和进度里的「针线」是同一个意思。

刺绣针脚做的分隔线，泥金色，取自最基本的平针。

用 `<hr class="hao-stitch">`。宽度跟随容器，你只决定放在哪里。

- 用在两大段内容之间、文章末尾落款之前，代替一条实线。列表行之间仍用 `hairline`，不用针脚。
- 它算一「景」，一屏至多一处，见手册的「三条规矩」。
- 颜色只用 `gold`，不改成 `tint` 或 `seal`。
- 同一种针脚线还用在三处，都是控件自己的形状，不算景：卡片的缝边（`hao-card--stitched`）、上传框的边、进度的「针线」。

**无障碍**

- 用真的 `<hr class="hao-stitch">`，读屏把它当一道分隔；换成 `<div>` 画线，这层意思就没了。
- 针脚是背景画的，不含文字，读屏不会读出任何东西。

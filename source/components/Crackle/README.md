冰裂纹底纹，取自窗棂和瓷器开片上不规则的裂线。

`<div class="hao-crackle" role="presentation">`，高 40px；纹样会横竖铺满所在的块。

- 颜色是 `pattern`，对比很低，只作底纹；上面不压文字和控件。
- 用在需要一块「窗」的地方：空状态的插画位、封面的一角、卡片的一侧。和海水纹二选一，不同屏可以换着用。
- 线是直的、不等长的，和海水纹的圆弧相对：水纹柔，冰纹硬。内容偏静、偏冷时用它。
- 它算一「景」，一屏至多一处，见手册的「三条规矩」。

**无障碍**

- 它是装饰，照预览写 `role="presentation"`，读屏不会读出任何东西。

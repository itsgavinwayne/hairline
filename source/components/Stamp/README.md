做完一件要紧的事时，盖下一方印。这是整套系统里唯一带「仪式感」的时刻。

`.hao-stamp` 里依次是一方 `.hao-seal.hao-seal--lg.hao-seal--outline.hao-seal--stamp`、`.hao-stamp__title`、`.hao-stamp__body`；标题和说明加 `hao-stamp__text`，会在印落定之后淡入。文字由你提供。

- 印文是「讫」。旧时票据、文书办完，盖一个「收讫」「验讫」，意思是这件事了结了。印文固定，不换成别的字；英文界面里也用它。
- 动效是一次落印：印从略大处压下来，轻轻一顿，回弹定住，共 420 毫秒；然后文字淡入。只播一次，不循环。
- 只用在真正了结一件事的地方：发布、提交、付款完成、读完一本书。保存、复制这类小动作用轻提示。一个流程里至多一次。
- 它就是这一屏的朱砂，同屏不再有别的印和红色角标。
- 加 `role="status"`，印本身 `aria-hidden="true"`，意思由标题说。
- 系统开启「减弱动态效果」时不播动效，印和文字直接出现。
- 用朱文（细边栏）。白文太重，压不住旁边的文字。
- 「讫」字现在是宋体占位。要换成篆字，照手册的「印稿规范」做一方「訖」字的朱文印稿。

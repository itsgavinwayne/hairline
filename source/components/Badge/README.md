贴在图标或条目旁的小数字，表示有几件事等着处理。

`<span class="hao-badge">数字</span>`；只想提示「有新的」而不说几个，用 `hao-badge--dot`；只是计数、不需要人处理的，用 `hao-badge--quiet`。

- 默认的角标是朱砂色，它就是这一屏的朱砂：同屏不再放印章，也不要出现两个红色角标。
- 超过 99 写「99+」。数到零就消失，不显示 0。
- 加 `aria-label` 把数字说成一句话（「3 条未读」）。
- 中性的数量（文件夹里有几条）用 `hao-badge--quiet`，或直接用列表行右侧的值。
- 带数字的角标是印的切角，四个角略不相等，不是胶囊形：它本来就是朱砂色，形也跟着印走。只有一个小点时仍是圆的。

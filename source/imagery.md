# 图形与素材

需要一个新图形，或者要找一张图的时候，先往中国的东西里找。这是一个方向，不是一份清单：系统不规定只能用哪几样，只规定往哪边找、怎么画、怎么选。

找到之后，用「审美标准与出处」里的五条筛一遍：素、空、淡、细、偏。合乎这五条的才用，不看它出自哪个朝代。

方向是开放的，数量是收着的。「三条规矩」照旧管着：朱砂一处，一屏一景，办事的页面不放景。

## 先往哪里找

先想清楚要表达什么意思，再找一样本来就有这个意思的东西。

| 要表达的 | 可以取的 |
| --- | --- |
| 书写、创作、编辑 | 文房：笔、墨、纸、砚、镇纸、印 |
| 时间、日程、提醒 | 节气、月相、日晷、更漏 |
| 入口、导航、空间 | 月洞门、窗棂、亭、桥、廊 |
| 收藏、整理、归档 | 匣、函套、书签、卷轴 |
| 完成、确认、署名 | 印、绳结 |
| 等待、空状态、自然 | 山、水、舟、月、竹、梅、松 |
| 装饰、分隔、底纹 | 回纹、海水纹、针脚、冰裂纹 |

表里没有的也可以用。取一样东西之前，先看系统里是不是已经有了：月、舟、山、亭、灯、印、三种纹样都已经画好。

## 界面里的图形怎么画

图标、空状态的小品、背景里的线描，都照这几条画。

- **取形，不取质感。** 画轮廓和结构，不画水墨晕染、飞白和做旧。一支笔画成笔杆、笔斗、笔毫三段线，不画成一道墨痕。
- **细线，平涂。** 线宽 1.5px，圆头圆角。封闭的轮廓留一个小缺口（留气口）。
- **颜色只用令牌。** 主体用 `tint` 或 `ink`，退到背景的用 `pattern`，点睛的线用 `gold`，淡淡的填色用 `tint-wash`。红色留给印。
- **一个图形一个意思。** 不把几样东西叠在一起。缩到 24px 还认得出来，才算画对了。
- **两个主题都要成立。** 画完在昼、夜两套主题下各看一遍。

文档网站首屏的那支笔就是这样来的：系统叫「毫」，毫是笔尖的毛，所以取了笔；画法是细线，笔毫用 `gold`，笔杆退到 `pattern`。

## 素材怎么选

照片、插画、纹理这类不是自己画的东西，照这几条选。

- **题材。** 器物、园林、山水、手工艺，以及纸、墨、布、木、瓷这些材质的近景。
- **色调。** 靠近系统的颜色：月白、瓷白、青、墨，加一点朱。避开大面积的正红和亮金。
- **构图。** 留白多，主体小，或者偏在一侧。一张图只有一个主体。
- **放在哪。** 水墨、拓片、古画的局部可以用，但只放在内容区：文章配图、海报、封面、装裱（`Mount`）里。不拿来做界面的底纹，上面不压文字。
- **授权。** 用之前查清楚。古画本身多半已过版权期，但收藏机构拍的照片可能另有使用条件。

要避开的几样：

- 龙、凤、祥云堆在一起，或者红灯笼、中国结这类成套的节庆装饰。内容本身讲的是节日时除外。单独一朵细线的云、一盏不上红色的灯，作为控件自己的形可以用（搜索框里的云头、书签的灯），照「形随控件」算。
- 仿古的做旧滤镜、泛黄的纸纹贴图。
- 生成的图里写错的汉字和不成形的书法。
- 只是「看起来像东方」的符号：筷子体的英文字、斗笠、折扇剪影。

想找个对照，看「审美标准与出处」里列的宋代作品：单色釉的瓷、留白的山水、宋版书的版式。

## 拿不准时问三句

1. 它和这里的内容有关系吗，还是只为了「像中国风」？没有关系就换一样，或者不放。
2. 拿掉它，页面照样成立吗？成立的话它就是景，一屏只能有一个。
3. 缩小、换到夜间主题、放到英文界面里，它还成立吗？

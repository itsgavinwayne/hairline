# Naming reference

Component names are full English words. Style class names use abbreviations to keep them easy to write, so the two don’t always match. Use this table when you write code. All class names start with `hao-`. Parts use two underscores (`hao-card__title`), and variants use two hyphens (`hao-card--wave`).

A few mappings that are easy to miss: the bookmark class name is `hao-lamp`, the moon phase progress is `hao-moon`, the empty state vignette is `hao-scene`, and the plum blossom is `hao-plum`.

The preview also has three helper classes that are only for layout, not components: `hao-stage` (the preview base), `hao-row` (horizontal row), `hao-stack` (vertical stack); plus `hao-page` and `hao-grid` for page layout.

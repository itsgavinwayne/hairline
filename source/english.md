# 英文界面

英文界面和中文界面是同一套系统：颜色、间距、圆角、组件、纹样都不变，变的只有字和话。在页面根元素写上 `lang="en"`，标题的字号和字距会自动切到英文的那一档。

## 字体

- 衬线标题的西文用 Newsreader，排在字体栈的最前面，汉字自动落到 Noto Serif SC。它的楔形衬线和粗细对比接近宋体的顿角与横细竖粗，两种文字放在一行里气质一致。
- 正文和控件的西文用系统的 San Francisco，和 iOS 原生一致。
- 英文标题用 `display-en`、`title-1-en`、`title-2-en`、`title-3-en`：字重比中文轻一档（500 或 600），字距收紧（-0.02em 到 -0.01em）。中文标题是放宽字距（+0.02em），两者不要互换。大的两级英文比中文大一号（34 对 32，48 对 44），因为汉字的字面更满；24 和 20 两级同号。
- 英文正文用 `body-en`，行高 24px，比中文的 28px 少 4px；`headline`、`callout`、`footnote`、`caption` 中英文共用。
- 英文段落每行 60 到 75 个字符。

## 大小写与强调

- 一律句首大写（sentence case）：“Save changes”，不写 “Save Changes”，更不写 “SAVE CHANGES”。
- 不用全大写做标签或小标题，也不用加宽字距的大写字母装饰。
- 强调用斜体，这是西文里最接近「落款小字」的传统；一段里至多一处。汉字永远不设斜体。
- 引号用弯引号（“ ”），撇号用 ’，范围用连接号（7–9 PM）。

## 说话的方式

和中文同一个性格：短、平、动词在前，不卖弄。

| 场景 | 中文 | 英文 |
| --- | --- | --- |
| 主按钮 | 保存修改 | Save changes |
| 删除 | 删除这条札记 | Delete this note |
| 成功 | 已发布 | Published |
| 报错 | 没连上网络，稍后再试 | Can’t reach the network. Try again in a moment. |
| 空状态 | 还没有札记，写下第一条 | No notes yet. Write the first one. |
| 状态标签 | 进行中 / 今天到期 / 已完成 | In progress / Due today / Done |

- 用 you，不用 we 自称；可以用缩写（can’t、you’re）。
- 不道歉，不用感叹号，不说 “Oops”、“Whoops”。
- 英文比中文长三成左右：按钮不超过三个词，分段控件每段不超过十个字符，标签不超过两个词。放不下就换一个更短的说法，不缩字号。
- 不用东方主题的套话：zen、ancient wisdom、harmony、journey 这类词不出现在界面里。东方的气质交给颜色、印章和留白，不交给形容词。

## 中文词怎么进英文

- 能直译的就直译成平常的词：札记是 note，案头是 desk，落款是 signature。不为了显得雅而留拼音。
- 没有对应词的专名（节气、干支）第一次出现时英文在前、汉字在后：“Minor Snow (小雪)”，之后只写英文。干支年写作 “the Bingwu year”。
- 夹在英文里的汉字包一层 `<span lang="zh">`，这样它用宋体或苹方，不会被设成斜体。
- 中英文之间留一个空格；标点跟随所在句子的语言。

## 日期与数字

| | 中文 | 英文 |
| --- | --- | --- |
| 日期 | 11 月 18 日 星期三 | Wednesday, November 18 |
| 短日期 | 11 月 18 日 | Nov 18 |
| 时间 | 07:12 | 7:12 AM |
| 相对时间 | 今天 07:12 | Today, 7:12 AM |

## 印章、题签与纹样

- **印章**保留汉字印，不换成字母。它是图形标志，在英文界面里就像信纸上的一方红印，不翻译；加 `lang="zh"` 和英文的 `aria-label`。
- **题签**不竖排西文。英文落款用 `colophon` 斜体横排，和小印并排。
- **针脚、回纹、海水纹**与语言无关，规则不变：一屏一种，不进控件。

## 同一个组件，两种语言

每个组件的预览都分「中文」「English」两段。大多数组件只是换了文字；下面这些在两种语言里长得不一样，是有意的。

| 组件 | 中文 | 英文 |
| --- | --- | --- |
| 标题 | 宋体，字重 600 到 700，字距放宽 | Newsreader，字重 500 到 600，字距收紧 |
| 段落 | 两端对齐，行高 28px，行首行尾的标点按中文规矩处理 | 左对齐，行高 24px，末行避免只剩一个词 |
| 引文 | 一对泥金角标，取「」的形 | 一个悬挂在左上的泥金开引号 “ |
| 步骤条 | 序号是一、二、三 | 序号是 1, 2, 3 |
| 日历 | 节气写在日期下面（立冬） | 日期下面一个泥金小点，月历下方列出 “Nov 7, Start of Winter” |
| 日历页 | 十一月 / 18 / 周三 | Nov / 18 / Wed |
| 头像 | 没有照片时取姓（林） | 没有照片时取两个首字母（LW） |
| 进度旁的文字 | 可以写「六成二」 | 写 62% |
| 评分旁的文字 | 四分 | 4 of 5 |
| 数字展示 | 数字后跟量词（31 条） | 数字后跟名词复数（31 notes） |
| 引用名称 | 「晨间札记」 | “Morning note” |
| 印章、题签 | 汉字 | 仍是汉字，作为图形；落款另用斜体的 colophon |

- 中文段落里，汉字和西文、数字之间的空隙由浏览器自动加（支持的浏览器上）；手写文案时仍然照「中西文之间留一个空格」写，两者不冲突。
- 标题不论中英文，换行时两行尽量等长。
- 按钮有 88px 的最小宽度，这样「取消」「删除」这类两个字的按钮不会显得太窄；英文按钮按文字自然撑开。

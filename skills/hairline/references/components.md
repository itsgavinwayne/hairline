# 组件一览

每行对应一个文件，里面是说明和可以直接抄的标记。用到哪个再打开哪个。

| 分组 | 组件 | 文件 | 是什么 |
| --- | --- | --- | --- |
| 图标 | Icon 图标 | `components/Icon.md` | 这套系统自己的图标：39 个，线性，单色。 |
| 纹样 | Crackle 冰裂纹 | `components/Crackle.md` | 冰裂纹底纹，取自窗棂和瓷器开片上不规则的裂线。 |
| 纹样 | Fret 回纹 | `components/Fret.md` | 一条回纹饰带，纹样来自商周青铜器，后来织进锦缎的边。 |
| 纹样 | Stitch 针脚 | `components/Stitch.md` | 刺绣针脚做的分隔线，泥金色，取自最基本的平针。 |
| 纹样 | Wave 海水纹 | `components/Wave.md` | 海水纹底纹，取自袍服下摆「海水江崖」里层层叠叠的水波。 |
| 动效 | Motion 进场动效 | `components/Motion.md` | 浮层出现时的几种进场方式，各对应一种浮层；另有一个「点灯」，属于书签。点「重播」再看一次。 |
| 操作 | Bookmark 书签 | `components/Bookmark.md` | 收藏的开关，样子是一盏挂着的灯：没收藏时是一盏空灯，收藏了就点亮。 |
| 操作 | Button 按钮 | `components/Button.md` | 触发一个动作的按钮，一屏只放一个主按钮。 |
| 表单 | Calendar 月历 | `components/Calendar.md` | 月历，用来选一个日期。日期下面可以带一行农历，或者一枚月相。 |
| 表单 | Checkbox 勾选框 | `components/Checkbox.md` | 从一组选项里勾选任意几项，提交后才生效。 |
| 表单 | Chip 筛选标签 | `components/Chip.md` | 可以点选的胶囊，用来筛选一个列表。 |
| 表单 | Radio 单选 | `components/Radio.md` | 从一组选项里只选一项。 |
| 表单 | Rating 梅花评分 | `components/Rating.md` | 五分制的评分，用一朵五瓣的梅花代替星星。 |
| 表单 | SearchField 搜索框 | `components/SearchField.md` | 搜索框，胶囊形，左边一个放大镜。 |
| 表单 | Segmented 分段控件 | `components/Segmented.md` | 在两到五个并列视图之间切换。 |
| 表单 | Select 下拉选择 | `components/Select.md` | 从六项以上的列表里选一项。样子照 iOS 的弹出按钮：淡染的底，石青的字，右边一对上下箭头。 |
| 表单 | Slider 滑块 | `components/Slider.md` | 在一个连续范围里拖动选值，适合不需要精确数字的设置。 |
| 表单 | Stepper 步进器 | `components/Stepper.md` | 用加减按钮一步一步调整一个小数字。 |
| 表单 | Switch 开关 | `components/Switch.md` | 立即生效的开与关。 |
| 表单 | TextField 输入框 | `components/TextField.md` | 单行文字输入，带标签和一行说明。 |
| 表单 | Upload 上传 | `components/Upload.md` | 选文件或把文件拖进来的区域。 |
| 导航 | Breadcrumb 面包屑 | `components/Breadcrumb.md` | 一行路径，告诉人现在在哪一层、怎么回到上面。用在宽屏、层级三层以上的地方。 |
| 导航 | Link 链接 | `components/Link.md` | 带人去另一个页面的文字链接。按它所在的位置，有三种写法。 |
| 导航 | NavBar 导航栏 | `components/NavBar.md` | 页面顶部的导航栏，告诉人现在在哪、怎么回去、这一页最主要的动作是什么。 |
| 导航 | Pagination 分页 | `components/Pagination.md` | 在很多页的列表或表格之间翻页，用在宽屏。 |
| 导航 | Sidebar 侧边栏 | `components/Sidebar.md` | 宽屏左侧的导航栏，顶层区域多于五个，或者下面还有一层（文件夹）时用它代替顶部导航。 |
| 导航 | Steps 步骤条 | `components/Steps.md` | 分几步完成一件事时，告诉人一共几步、现在在第几步。序号用汉字数字。 |
| 导航 | TabBar 标签栏 | `components/TabBar.md` | 屏幕底部的标签栏，在产品的几个顶层区域之间切换。 |
| 导航 | Tabs 标签页 | `components/Tabs.md` | 页面内的标签页，在同一层级的几块内容之间切换，主要用在中屏和宽屏。 |
| 内容 | Accordion 折叠面板 | `components/Accordion.md` | 点一下标题展开下面的内容，用来收起次要的、不是每个人都要看的信息。 |
| 内容 | Avatar 头像 | `components/Avatar.md` | 代表一个人的圆形头像。 |
| 内容 | Card 卡片 | `components/Card.md` | 承载一段独立内容的卡片，标题用宋体。 |
| 内容 | DateTile 日历页 | `components/DateTile.md` | 一张小小的日历页，把一个日期当成图形摆在日程或事件旁边。 |
| 内容 | Divider 分隔线 | `components/Divider.md` | 长文里分隔两大段的线，中间一枚「鱼尾」。 |
| 内容 | ListGroup 分组列表 | `components/ListGroup.md` | iOS 式的分组列表，设置页和详情页的主体。 |
| 内容 | Quote 引文 | `components/Quote.md` | 引一句别人的话，用一对角标框起来，取自中文引号「」的形。 |
| 内容 | Stat 数字展示 | `components/Stat.md` | 把一个重要的数字放大了摆出来。 |
| 内容 | Table 表格 | `components/Table.md` | 在宽屏上并排比较多条记录的表格。 |
| 内容 | Timeline 时间线 | `components/Timeline.md` | 按时间先后列出的一串事件，每个节点是一轮月。 |
| 反馈 | Dialog 弹窗 | `components/Dialog.md` | 打断当前操作、必须先回答的弹窗。 |
| 反馈 | EmptyState 空状态 | `components/EmptyState.md` | 一块区域里没有内容可显示时的画面：一幅圆窗里的小品、一句现状、一句下一步。 |
| 反馈 | Progress 进度与加载 | `components/Progress.md` | 「正在进行」的几种表达。形状借了三个传统意象：月相、针线、漏刻。 |
| 反馈 | Sheet 底部弹层 | `components/Sheet.md` | 从底部升起的弹层，放一组针对当前内容的动作或一小段表单。 |
| 反馈 | Stamp 盖印 | `components/Stamp.md` | 做完一件要紧的事时，盖下一方印。这是整套系统里唯一带「仪式感」的时刻。 |
| 反馈 | Toast 轻提示 | `components/Toast.md` | 操作之后短暂出现的一句回执，不打断人。 |
| 浮层 | Menu 菜单 | `components/Menu.md` | 点一下「更多」或长按之后弹出的一小组动作，贴着触发它的东西出现。 |
| 浮层 | Tooltip 气泡提示 | `components/Tooltip.md` | 鼠标悬停或键盘聚焦时出现的一句说明，给只有图标的按钮起名字。 |
| 状态 | Badge 角标 | `components/Badge.md` | 贴在图标或条目旁的小数字，表示有几件事等着处理。 |
| 状态 | Banner 提示条 | `components/Banner.md` | 页面内的一条提示，说明发生了什么、接下来怎么办。 |
| 状态 | Tag 标签 | `components/Tag.md` | 标出一条内容当前的状态，不可点。 |
| 阅读 | Handscroll 手卷 | `components/Handscroll.md` | 横向滚动的一卷内容，像展开一幅手卷：最前面是题名，然后一段一段向后看。 |
| 阅读 | Mount 装裱 | `components/Mount.md` | 把一张重点图片「装裱」起来：四周留出绫边，竖幅的下面有一根轴。 |
| 阅读 | Paper 笺纸 | `components/Paper.md` | 一张笺纸：带界栏的信纸，用来写和读篇幅不长、带点郑重的文字。 |
| 阅读 | Prose 长文 | `components/Prose.md` | 长文的阅读版式：一篇文章从标题到落款该怎么排。 |
| 阅读 | Verse 竖排的诗 | `components/Verse.md` | 竖排的诗，或一段值得单独摆出来的短句。这是系统里唯一让正文竖着走的地方。 |
| 平面 | Poster 海报 | `components/Poster.md` | 海报、社交图、幻灯片封面的模板。同一个容器，三种比例。 |
| 品牌 | Logo 标志 | `components/Logo.md` | Hairline 这套系统自己的标志：一方朱砂印，印面里一轮月、一道水线，旁边是字标。 |
| 品牌 | Seal 印章 | `components/Seal.md` | 一方朱砂印，是使用这套系统的人或产品自己的署名，按篆刻的规矩做成白文和朱文两种。 |
| 品牌 | SealGuide 印面示意 | `components/SealGuide.md` | 做一方印稿时用的印面示意：白文、朱文、四字印各一张，标了尺寸和字区。它是给做印的人看的图，不是放进界面的组件。 |
| 品牌 | TitleSlip 题签 | `components/TitleSlip.md` | 竖排的题签，仿线装书封面左上角贴的那张书名签。 |

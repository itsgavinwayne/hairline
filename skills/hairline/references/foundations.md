# 网页与大屏

这套系统从手机长出来，但不止于手机。屏幕变宽时，原则不变：先留白，一屏一件事，石青行事。变的是布局、导航的位置，和多出来的鼠标。

## 三级窗口

| 级别 | 宽度 | 栅格 | 页边距 | 顶层导航 |
| --- | --- | --- | --- | --- |
| 窄 | 小于 600px | 4 列，间距 16px | `margin-compact` | 底部 `TabBar` |
| 中 | 600 到 839px | 8 列，间距 `gutter` | `margin-medium` | 底部 `TabBar` 或顶部导航 |
| 宽 | 840px 以上 | 12 列，间距 `gutter` | `margin-expanded` | 顶部导航 |

- 用 `.hao-page` 做页面容器，`.hao-grid` 做栅格，列数会随窗口自动变。内容区到 `content-max` 就不再变宽。
- 先设计窄屏，再往宽里加；不要把宽屏的页面硬缩成窄屏。
- 长文正文的行宽不超过 `measure`，哪怕屏幕再宽。
- 同一份内容换形态而不是换内容：窄屏的 `ListGroup` 到宽屏变成 `Table`，窄屏的 `Sheet` 到宽屏变成居中的 `Dialog`，窄屏整页的详情到宽屏变成右侧一栏。

## 鼠标与键盘

- 悬停只是提示「这里能点」，不承载信息：填充按钮换成 `tint-hover` 或 `seal-hover`，行和菜单项换成 `surface-hover`。悬停样式只在有鼠标的设备上出现。
- 不要把内容藏在悬停后面。触屏上没有悬停，凡是悬停才出现的操作，在触屏上要有别的入口。
- 所有能点的东西都能用 Tab 键走到，焦点环是 `focus` 色 2px 实线。顺序跟着视觉顺序走。
- 触屏上可点的东西不小于 44px；纯鼠标操作的密集区域（表格行内的小按钮）可以放宽到 32px。

## 状态

每个控件都要想清这几种状态，缺了哪个都算没做完：

| 状态 | 表现 |
| --- | --- |
| 默认 | 令牌的本色 |
| 悬停 | `tint-hover`、`seal-hover`、`surface-hover` |
| 按下 | 按钮缩到 97%，不透明度 `opacity-pressed`；别的小控件只降不透明度；整行的（列表行、菜单项、侧栏项、折叠标题）换成 `surface-sunken` 底 |
| 聚焦 | `focus` 色 2px 实线，外扩 2px；贴着容器边的（列表行、菜单项、标签页）内收 2px，免得被裁掉 |
| 选中 | `tint` 填充，或 `ink` 加粗配一道 `tint` |
| 只读 | 输入框去掉填充，描边退成 `hairline`，字仍是 `ink`，仍能聚焦和选中 |
| 禁用 | 按钮和输入框换成 `surface-sunken` 底、`ink-tertiary` 字；勾选、开关、分段、滑块、筛选标签、步进、页码整体 `opacity-disabled`，旁边的文字换成 `ink-tertiary`。指针都变成禁止，并在旁边说明原因 |
| 出错 | `seal` 的 2px 描边，加一句说明 |
| 加载 | 少于一秒不显示；之后用 `Progress` 里的一种 |

## 动效

动效只回应操作，说明「东西从哪来、到哪去」，不做装饰。

| 名称 | 时长 | 用在哪里 |
| --- | --- | --- |
| `dur-fast` | 120ms | 按下、悬停、勾选 |
| `dur-base` | 200ms | 开关、分段滑块、标签切换 |
| `dur-slow` | 320ms | 弹窗、底部弹层、页面转场 |

- 进入用 `ease-out`（快起慢停），位置移动用 `ease-in-out`。离开比进入快三分之一。
- 弹层从它将要停留的方向来：底部弹层用「展卷」，由下而上展开；弹窗原地淡入并从 96% 放大；轻提示从下方浮起。对应的类和演示见 `Motion`。
- 完成一件要紧的事时「盖印」：一方「讫」字印落下，一顿，定住。全系统只有这一处带仪式感的动效，见 `Stamp`。
- 不做循环动画，不做滚动时逐段淡入。唯一持续在动的是转圈。
- 系统开启「减弱动态效果」时，位移和缩放都改成淡入淡出。

## 层级

从低到高：页面内容，`z-nav`（吸顶导航、吸底标签栏），`z-sheet`（遮罩与底部弹层），`z-dialog`（弹窗），`z-popover`（菜单与气泡提示），`z-toast`（轻提示）。不自己造数字。

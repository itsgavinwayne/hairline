# 印稿规范

印章是这套系统的署名。组件 `Seal` 里默认用宋体字占位，够用，但不是真正的印。想要一方像样的印，需要另做一份「印稿」：一个画好了篆字的矢量图，放进 `Seal` 里替换掉占位的字。

这套系统**不提供任何篆字**。篆书的字形和今天的写法差得很远，写错一笔就是错字；字形又大多有版权。所以这里只讲规矩和尺寸，字由你自己准备。示意图见 `SealGuide`，空白印面在资源的 Seals 组里。

## 先定四件事

| 定什么 | 选项 | 怎么选 |
| --- | --- | --- |
| 印文 | 一个字、两个字或四个字 | 姓氏、名字或产品名。一个产品只用一个印文 |
| 刻法 | 白文（朱底白字）或朱文（朱字带边栏） | 品牌露出处用白文，落款处用朱文。两种可以各做一方，印文相同 |
| 字体 | 小篆，或汉印的方折写法（缪篆） | 白文配方折的写法，横平竖直，容易撑满印面；朱文配圆转的小篆 |
| 印面 | 正方，或长方（两字竖排） | 单字、四字用正方；两字用长方，宽是高的六成 |

## 字形从哪来

- **以《说文解字》为准。** 每个字先查它的小篆写法，不要照楷书的样子自己「篆化」，那样做出来的多半是错字。简化字要先找到它对应的繁体或本字，例如「讫」查「訖」。
- **可以用字体，但要看清许可。** 一个可查的来源是台湾中研院「小学堂」发布的崇羲篆体，收《说文解字》和常用字共一万一千多字，网址是 `xiaoxue.iis.sinica.edu.tw/chongxi`。它的许可是「姓名标示-禁止改作 3.0 台湾及其后版本」：可以使用，包括商业使用，但要标明原作者，并且**不能修改字形**。也就是说只能原样排字，不能在它的字上加粗、改笔画。用之前请自己读一遍它的许可页面，以那里的条款为准。
- **请人写、请人刻，是最稳妥的。** 懂篆刻的人会顺手处理好章法（字在印面里怎么摆），这是字体做不到的。
- **不要用**苹果、微软这些系统自带的字体转成图形，它们不允许这样用。
- 不管字从哪来，定稿前请一位认得篆字的人看一眼。

## 尺寸

画布 48×48 个单位，印面占中间的 40×40，从（4, 4）到（44, 44）。四个角的圆角分别是左上 5、右上 3、右下 6、左下 4，和系统里的 `Seal` 一致。

| | 白文 | 朱文 |
| --- | --- | --- |
| 印面 | 整块朱砂色 | 只有边栏 |
| 边栏 | 无 | 宽 1.8，底边 3 |
| 字区 | 34×34，四周留红 3 | 30×29.5，离边栏 3 |
| 笔画粗细 | 字区边长的八分之一到九分之一 | 和边栏差不多，1.4 到 1.8 |
| 笔画之间的空 | 和笔画一样宽，或略窄 | 是笔画的两到三倍 |

- **白文要「满」。** 字撑满字区，笔画粗，留下的红和笔画的白大致各占一半。这叫「计白当黑」：空的地方和实的地方一样要经营。
- **朱文要「透」。** 笔画细，字和边栏之间留出空。个别笔画可以伸出去碰到边栏，叫「借边」，一方印里至多一两处。
- **多字印**：字与字之间留 1.6 个单位。四字印两行两列，自右上起竖读（右上、右下、左上、左下）；两字印竖排，上下各一字。笔画少的字可以让它占小一点的地方，把位置让给笔画多的字。
- **长方印**：印面 24×40，其余规矩相同。

## 文件怎么做

- 矢量图，SVG，画布 `viewBox="0 0 48 48"`，长方印是 `0 0 32 48`。
- 白文：一个路径，印面是外轮廓，字是里面镂空的洞，用 `fill-rule="evenodd"`。朱文：边栏一个路径，字一个路径。
- 只用一种颜色。浅色底用 `#b83224`，深色底另出一份 `#ff8a75`。不加渐变、阴影、纹理和做旧的残破。
- 字要转成轮廓，不留活字。
- 16px 下要认得出是一方印，40px 下要能看清笔画。太细的笔画在小尺寸下会断，朱文尤其要试。

## 放进系统

```html
<span class="hao-seal hao-seal--art" role="img" aria-label="某某 印">
  <img src="你的印稿.svg" alt="">
</span>
```

- 尺寸类照用：`hao-seal--sm`、默认、`hao-seal--lg`、`hao-seal--xl`。
- 要随昼夜主题换色，就把 SVG 直接写进页面，路径的颜色用 `var(--seal)`，不用 `<img>`。
- 盖印动效同样可用，加 `hao-seal--stamp`。
- `aria-label` 写产品或人的名字加「印」，不写印文的读法。

## 完成前核对

- 每个字都对照《说文解字》查过，或者由懂篆字的人看过。
- 字形的来源和许可写得清楚，该署名的署了名。
- 白文、朱文在 24px、40px、64px 下各看过一遍。
- 浅色和深色底上各看过一遍。
- 印面的四个角、边栏的粗细和这份规范一致。
- 同一个产品里所有地方用的是同一个印文。

## 关于「讫」

盖印组件 `Stamp` 里的「讫」字也是宋体占位。它是系统的一部分，不是某个产品的署名，所以没有随系统附带印稿。想让盖印那一下更像真的，照上面的规矩做一方「訖」字的朱文印稿换上即可。

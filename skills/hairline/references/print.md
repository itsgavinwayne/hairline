# 平面与印刷

海报、社交图、幻灯片、印刷品，用的还是同一套颜色、字和规矩，只是没有了交互，画面要自己站得住。模板见 `Poster`。

## 版式

- **边距**：四边各留画面短边的十二分之一。内容都对齐到这条边，只有海水纹和满底色可以出血。
- **栅格**：横向分十二列。大标题占四到八列；竖排标题占最右的两到三列。
- **留白**：空着的地方不少于画面的一半。
- **重心**：大的东西放上面或右边，信息和落印放底部。左下是信息，右下是印。

## 字

字号按画面短边的比例定，这样从手机图到一米高的海报都是同一个样子。界面里以像素计的那套阶梯（`display` 到 `caption`）不用在平面上。

| 用途 | 字体 | 大小（占短边） |
| --- | --- | --- |
| 大标题（中文） | 宋体 700 | 13% 到 16% |
| 大标题（英文） | Newsreader 500 | 11% 到 14% |
| 副题 | 宋体 600 / Newsreader 500 | 5% 到 6% |
| 信息 | 黑体 400 | 3.5% 到 4% |

- 一张里只有一个大标题，两级字号之间至少差两倍。
- 中文大标题可以竖排，自右向左，不超过两列、每列不超过六个字。英文不竖排。
- 标题不加句号，不用感叹号，不居中（竖排除外）。

## 字体从哪来

| 用途 | 字体 | 授权 |
| --- | --- | --- |
| 中文标题 | Noto Serif SC（思源宋体） | SIL 开源字体许可，可商用、可印刷 |
| 西文标题 | Newsreader | SIL 开源字体许可，可商用、可印刷 |
| 正文与信息 | Noto Sans SC（思源黑体） | SIL 开源字体许可，可商用、可印刷 |

- 界面里，Apple 设备上正文仍用系统自带的苹方和 San Francisco；它们只授权在 Apple 平台的界面里用，**不能用于海报、印刷品、安卓和 Windows**。
- 所以平面物料、非 Apple 平台的界面，正文一律用思源黑体。字体栈里它排在苹方之后，没有苹方的地方会自动落到它。
- 三支字体都可以从 Google Fonts 取得。用于印刷前，请自行核对当时的许可条款。

## 颜色

屏幕上用令牌里的十六进制值。印刷时参考下表的四色值。

| 名字 | 令牌 | 屏幕 | 四色近似值 C / M / Y / K |
| --- | --- | --- | --- |
| 月白 | `bg` | #f2f4f7 | 2 / 1 / 0 / 3 |
| 瓷白 | `surface` | #ffffff | 0 / 0 / 0 / 0 |
| 玄青 | `ink` | #161b24 | 39 / 25 / 0 / 86 |
| 黛 | `ink-secondary` | #4a5263 | 25 / 17 / 0 / 61 |
| 石青 | `tint` | #1f4fa8 | 82 / 53 / 0 / 34 |
| 石青淡染 | `tint-wash` | #e3ebfa | 9 / 6 / 0 / 2 |
| 朱砂 | `seal` | #b83224 | 0 / 73 / 80 / 28 |
| 竹青 | `jade` | #24705a | 68 / 0 / 20 / 56 |
| 藤黄 | `amber` | #f2b632 | 0 / 25 / 79 / 5 |
| 泥金 | `gold` | #836427 | 0 / 24 / 70 / 49 |
| 纹样色 | `pattern` | #cfdaf0 | 14 / 9 / 0 / 6 |

- **这些四色值是从屏幕色直接换算的近似值，没有经过色彩管理，也没有打样核对。** 正式印刷前要让印厂按纸张出样，以样张为准；朱砂和石青这两个主色建议另配专色。
- 一张里的颜色不超过三种：一种底色，一种字色，加上石青或朱砂中的一个。
- 朱砂只用于印。大面积的颜色只用月白或石青。
- 泥金只用于细线（回纹、角标）；真的要印金色时用专色金，不要用四色去叠。

## 景与印

- 一张一景：海水纹、回纹、一轮月、一幅装裱的图、一首竖排的诗，五选一。
- 一张一印，放右下角，印面宽度是短边的十分之一左右。
- 印稿用于印刷时要用矢量文件。标志的文件在资源的 Logos 组里；产品自己的印需要另备矢量稿。

## 尺寸与输出

| 用途 | 比例 | 常用尺寸 |
| --- | --- | --- |
| 海报 | 2:3 | 屏幕 1080×1620 像素；印刷按纸张，四边各加 3 毫米出血 |
| 社交方图 | 1:1 | 1080×1080 像素 |
| 幻灯片、头图 | 16:9 | 1920×1080 像素 |

- 印刷品的字和印离裁切边至少 5 毫米。
- 屏幕用图导出为 PNG；印刷导出为 PDF，字体转为轮廓或内嵌。

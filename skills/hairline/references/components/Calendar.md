# Calendar · 月历

月历，用来选一个日期。日期下面可以带一行农历，或者一枚月相。

`.hao-cal` 里是 `.hao-cal__head`（宋体月份标题和翻月按钮）、`.hao-cal__grid`（七列：一行星期，然后是日期按钮 `.hao-cal__day`），和可选的 `.hao-cal__foot`。今天加 `aria-current="date"`，选中的加 `aria-pressed="true"`，上下月补位的加 `hao-cal__day--out`。

**日期下面放什么，三选一**

| 方式 | 写法 | 样子 |
| --- | --- | --- |
| 农历 | `<small class="hao-cal__lunar">初十</small>` | 每天一行农历日；初一那天写月名（十月），加 `hao-cal__lunar--first`；节气那天换成节气名，用不带类名的 `<small>`，泥金色 |
| 月相 | `<i class="hao-moon hao-moon--xs" style="--p:.6">` | 每天一枚小月亮；下半月加 `hao-moon--wane`，亮面换到左边 |
| 什么都不放 | | 最干净，用于只是选个日期的场合 |

- 一个月历里只用一种，不要农历和月相都放，格子装不下。
- **月相**的 `--p` 是亮面的比例，0 是朔（初一），1 是望（十五前后）。上半月亮面在右，下半月在左，这是北半球看到的样子。
- **页脚**（`.hao-cal__foot`）写今天的干支年和农历日；用月相或英文时，把当月的节气也列在这里。
- **英文界面**不显示农历文字，用月相；节气在页脚列出英文名。
- 一周从周一开始。英文界面可以按当地习惯从周日开始。
- 今天是 `tint` 色加粗，选中是 `tint` 填充；两者重合时按选中显示。
- 方向键在日期间移动，回车选中，翻页键换月。

**数据从哪来**

- 农历日期不能手写，也不能自己推算，要用历法数据。浏览器和系统自带的国际化接口就有（把日历设为 `chinese`），能给出月、日和干支年。
- 月相可以由农历日直接换算：初一是朔，十五前后是望。要精确到当天的实际月相，用天文历算库。
- 节气要用历算库或官方发布的表。预览里的立冬、小雪和农历日期，是用系统历法数据生成的 2026 年 11 月。

**行为**（加载了行为脚本时）

- 给 `<div class="hao-cal">` 加 `data-hao-calendar`，脚本会接管里面的内容，画出真正的月历。属性：`data-mode`（`lunar`、`moon` 或 `plain`）、`data-value`（选中的日期，`2026-11-20` 这样写）、`data-today`（把「今天」固定在某一天，演示用；不写就是真的今天）、`data-terms="off"`（不标节气）。
- 翻月按钮可用。点一天就选中它，日历发出 `hao-change` 事件，带上日期和农历。
- 键盘：方向键按天、按周移动，移出本月会自动翻月；Home 和 End 到本周头尾；PageUp 和 PageDown 翻月；回车或空格选中。整个月历只占一个 Tab 停靠点。
- 脚本画出的月历是「表格、行、格」三层结构（`.hao-cal__row` 一周一行，`.hao-cal__cell` 包着日期按钮），读屏能报出星期几和第几周。
- 每个日期都有完整的读法（年月日、星期、农历、节气）供读屏使用。
- **农历和月相是实时算的**，用的是浏览器自带的中国历法数据。浏览器不支持时自动退回不带农历的样子。
- **浏览器的农历数据在极少数日子会差一天。** 朔正好落在午夜前后时，它可能把初一算到相邻的那天；实测 2027 年 2 月 6 日它给的是腊月三十，而那天应当是正月初一。日常展示够用；要拿来定节日、算生日这类不能错的事，把 `Hairline.calendar.source` 换成一个接收日期、返回农历的函数，接上权威的历法数据。
- **节气用的是近似算式**，个别年份会差一天，只覆盖 2001 到 2100 年。要准确，把 `Hairline.calendar.terms` 换成一个返回历算数据的函数。
- 没有加载脚本时，容器里原来写的静态月历照常显示。
